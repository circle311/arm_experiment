第一部分：MCU 端基础功能
1.   系统时基 + 软定时器
接口：
 volatile uint32_t g_tick_ms;
 volatile uint8_t     flag_5ms, flag_10ms, flag_100ms, flag_1s;
 void      SysTick_Handler(void);
 uint8_t     Tick_TimedOut(uint32_t start, uint32_t span_ms);


数据流：SysTick(1ms) → g_tick_ms++ → 按取模设置标志位 → 主循环消费清零
验收：
  SysTick 优先级最低

  1 秒走时误差 < 0.1 s

  主循环无 Delay_ms() 阻塞
常见坑：中断里做"重活"、 g_tick_ms 未加 volatile

2. I2C   七段数码管显示
接口：
 #define DISP_LEN 8
 extern uint8_t disp_buf[DISP_LEN], disp_dp[DISP_LEN], disp_blink_mask, disp_on;
 void Display_Init(void);
 void Display_Refresh(void);
 void Display_SetStr(const char *s, uint8_t dp_bitmap);


段码表：数字 0-9、字母 A-Z、符号 - _ °
验收：
  I2C 400K 无暗位

  8 位均匀亮度

  静态/闪烁切换无抖动
常见坑：上一位关断不彻底导致鬼影、FORMAT RIGHT 时小数点用"下一位"规则
3.   按键扫描
接口：
 typedef enum {
      KEY_NONE=0, KEY_FUNC, KEY_SHIFT, KEY_ADD, KEY_SAVE,
      KEY_DISP, KEY_SPEED, KEY_FORMAT, KEY_EXT, KEY_USER1, KEY_USER2
 } key_code_t;
 typedef enum { KEV_NONE, KEV_DOWN, KEV_UP, KEV_LONG, KEV_REPEAT } key_event_t;
 void Key_Scan(void);
 key_event_t Key_GetEvent(key_code_t *out);


状态机：IDLE → PRESSED → LONG_PRESSED（防抖 20ms，长按 ≥800ms）
验收：
  1 秒内连续按 3 次以上不丢键

  FUNC 长按 ≥800ms 触发 LONG

  USER1/USER2 同样进入键值队列

常见坑：阻塞 delay 防抖、未区分 DOWN/UP 事件

4. UART     接收中断 + 行整理
接口：
 #define LINE_MAX 64
 extern volatile uint8_t rx_line_ready;
 extern char cmd_line[LINE_MAX];
 void UART_Init(uint32_t baud);
 void UART_RxIsrHandler(uint8_t byte);


数据流：UART RX ISR → 环形缓冲 → 遇 \r / \n 置位 → 主循环整理（去空格/转大写）→ 分发
验收：
     115200, 8N1

  支持 \r 、 \n 、 \r\n
  粘包/多空格正确整理
  行长 >64 丢弃并提示 ERROR LINE TOO LONG
常见坑：中断里处理命令、 *SET:MSG 后内容被误转大写（须保留原文）
5.   开机画面
时序（每段 800-1000ms）：
 1. 8 LED + 8 数码管全亮→全灭，闪烁≥1 次

 2. 显示学号后 8 位，闪烁 1 次

 3. 显示姓名拼音，闪烁 1 次

 4. 显示版本号 V 1.0 持续 1s

 5. 进入时钟显示

验收：学号/姓名与提交一致、时长 4-8s

6.   日期/时间显示
数据结构：
 typedef struct { uint16_t y; uint8_t m, d, wday; } date_t;
 typedef struct { uint8_t h, mi, s; } time_t_;


显示约定：时间 HH.MM.SS 、日期 YY.MM.DD 或 YYYY.MMDD
验收：
  闰年 02/29→03/01 正确
  月末进位正确
  23:59:59→00:00:00 正确



7.   左/右流水显示
接口：
 typedef enum { FMT_LEFT, FMT_RIGHT } format_t;
 void Scroll_Set(const char *text, uint8_t dp_bitmap);
 void Scroll_Tick(void);


算法：维护 scroll_buf[N] （N≥32）+ 偏移指针 off ，边界回绕
小数点跟随规则：
  FMT_LEFT：小数点用本位

  FMT_RIGHT：小数点用下一位

速度：500ms/步（慢）/ 250ms/步（快），SPEED 键（K6）切换
验收：
  左/右流水正常
  两级速度可见差异
     小数点位置切换时立刻调整

8.   闹钟
数据结构：
 typedef struct { time_t_ t; uint8_t enabled, ringing; } alarm_t;


行为：
  每秒比对 g_time == g_alarm.t 且 enabled → 响铃
  节奏式响铃（200ms 响/200ms 停），持续 ≤10 秒自动停止
  FUNC 立即停止，响铃期间 FUNC 优先于编辑切换

  无贪睡功能（学生版 §3.4 明确不要求）
验收：
  到点必响
  ≤10 秒自动停

  FUNC 立即关

  LED 指示：使能=常亮，响铃=快闪



9.   编辑有限状态机
状态机：
 IDLE → EDIT_DATE → EDIT_TIME → EDIT_ALARM → IDLE（FUNC 短按循环）


 任意 EDIT 状态：
     SHIFT: 高亮位左移   ADD: 当前字段+1
     SAVE/FUNC长按: 保存退出   5s无操作: 放弃退出


验收：
        短按循环切换
     FUNC

  SHIFT 高亮闪烁

  ADD 进位/钳制正确

  5s 无按键自动退出且不保存

常见坑：退出时高亮掩码未清零、编辑期间用 delay 阻塞秒走时
10.   串口指令完整集
必须支持的指令：
 命令       子命令                                参数
 *RST     —                                  复位时钟/日期/闹钟，DISP=ON，FORMAT=LEFT
 *SET     :DATE                              YEAR/MONTH/DATE（单参或组合）

 *SET     :TIME                              HOUR/MINute/SECond

 *SET     :ALARM                             HOUR/MINute/SECond/OFF

 *SET     :DISPlay                           ON/OFF

 *SET     :FORMAT                            LEFT/RIGHT

 *SET     :MSG                               ≤32   字节滚动消息（保留大小写）
 *SET     :BEEP                              10-5000ms

 *SET     :LED                               2位 HEX
 *SET     :KEY                               NAME（10 项，执行后不上报 EVT:KEY）

 *SET     :MODE                              DAY/NIGHT

 *GET     :DATE/:TIME/:ALARM/:DISP/:FORMAT   查询
 *PING    —                                  心跳，应答 *PONG <uptime_s>
兼容性硬指标：
   大小写不敏感
   空格容错（1+ 个空格）
   缩写：输完大写字母即合法（如 *SET:TIME HOUR MIN SEC ）
   多参数≥3 种组合
   错误回应 ERROR SYNTAX/PARAM/RANGE
FORMAT RIGHT 影响：

   所有 *GET 应答字符串逆序
   数码管同步逆序，小数点按 §7 规则跟随

 LED                含义                      频率

第二部分：MCU 端协同扩展
12.   滚动消息 *SET:MSG <text>
协议：PC→MCU，文本≤32 字节，保留原大小写，应答 OK
行为：
  ≤8 位：静态显示 2-3 秒后自动返回时钟

  >8 位：自动进入流水模式（无需启停键）
  流水完整一遍后自动返回时钟
  流水期间按任意键（除编辑键）立即中断
验收：大小写保留、LEFT/RIGHT 均正确、流水期间秒不丢

13.   远程蜂鸣 *SET:BEEP <ms>
协议：10-5000ms，越界 ERROR RANGE
验收：100/500/2000ms 三档准确（±20ms）、与闹钟不冲突

14.   远程 LED 直控 *SET:LED <hex>
行为：覆盖默认 LED 含义，收到 00 或 *RST 退出接管
验收：任意组合可点亮、接管时心跳停止、复位后恢复

15.   天气接收 *SET:WEA <T> <COND>
协议：温度 -40~+50，天气码 SUN/CLD/OVC/RAI/SNO/FOG
LED 编码：

    LED4：SUN 常亮

    LED5：RAI/SNO 1Hz 呼吸

    LED6：≥30°C 常亮

闹钟-天气联动：雨雪时多响 3 声、高温时 8LED 慢闪

16.   主动事件上报 *EVT: 系列
报文清单：
 报文                                 触发
  *EVT:KEY <NAME>                   物理按键（ *SET:KEY 不上报，避免环回）
  *EVT:ALARM / *EVT:ALARM_OFF       闹钟开始/停止
  *EVT:EDIT <TYPE> <VALUE>          编辑保存
  *EVT:DISP <8字符> <dpHex>           显示变化或 1s 心跳
  *EVT:LED <hex>                    LED 变化或 1s 心跳

  *EVT:MODE <STATE>                 模式切换
*EVT:DISP   编码：
   字符定长， _ 填空，不含小数点
      8

  空格 + 2 位 HEX 表示小数点位图
  每秒发送一次（即使无变化），1Hz 全量心跳
验收：PC 镜像延迟<200ms、1s 心跳持续到达

17. NTP     同步状态指示
状态机：UNSYNCED（LED7 灭）→ SYNCED（常亮）→ DRIFT（>24h，1Hz 慢闪）
长按 USER1 查询：显示 n.SY.xx 3 秒（n=小时数，SY=标识，xx=状态）

18. USER2        短显天气
行为：USER2 短按 → 显示 <温度>°C <天气> 5 秒 → 自动返回
边界：无天气数据时显示 --°C --- 、数据过期闪烁

19. PING/PONG        心跳
协议：PC→ *PING ，MCU→ *PONG <uptime_s>
验收：应答时延<50ms、uptime 准确

MCU       协同端常见坑
      *SET:MSG 被大写整理破坏 → 整理前识别前缀保留原文
      *EVT:DISP 上报频率过高 → 加变化检测 + 速率限制

      B7 倒计时阻塞秒走时 → 基于 SysTick，不能 delay

      LED 接管与天气/NTP 冲突 → 接管时统一覆盖，退出后恢复
