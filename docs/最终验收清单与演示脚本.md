# S800 智能联网时钟最终验收清单与演示脚本

本文档用于最终自测、录屏和答辩演示。建议录屏前完整走一遍，确认每一步的现象都稳定。

## 1. 准备工作

### 1.1 硬件准备

- S800 扩展板与 EK-TM4C1294XL 主控板连接正常。
- USB 线连接 PC 与主控板。
- 板端已通过 Keil 下载最新版 `ARM/exp3-1.c`。
- 串口监视器或 PC 上位机使用同一个 COM 口，避免两个程序同时占用串口。

### 1.2 PC 环境准备

在项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\pc_host\verify_env.ps1
```

期望结果：

- `Python 3.11.9`
- `arch = 64bit | bits = 64`
- `PyQt5 ... | pyserial 3.5 | OK`
- `pyuic5` 能正常输出版本

启动 PC 上位机：

```powershell
.\pc_host\.venv\Scripts\python.exe .\pc_host\main.py
```

### 2.2 SSCOM 手动协议验收

串口参数：`115200 8N1`，ASCII，发送行尾建议使用 CRLF。

| 编号 | 输入 | 正确回复 | 板端表现 |
|---|---|---|---|
| S1 | `*PING` | `RX: *PING` 后 `*PONG <uptime>` | 无特殊动作 |
| S2 | `*SET:DATE YEAR MONTH DATE 2026 06 10` | `OK DATE` | 日期被设置 |
| S3 | `*SET:TIME HOUR MIN SEC 15 08 25` | `OK TIME` | 时间更新到指定值 |
| S4 | `*GET:TIME` | `TIME HH:MM:SS` | 无特殊动作 |
| S5 | `*GET:DATE` | `DATE YYYY-MM-DD` | 无特殊动作 |
| S6 | `*SET:BEEP 500` | `OK BEEP` | 蜂鸣约 0.5 秒 |
| S7 | `*SET:BEEP 9999` | `ERROR RANGE` | 错误用例，蜂鸣不应异常持续 |
| S8 | `*SET:LED 3F` | `OK LED` | LED0-LED5 点亮，进入 LED 接管 |
| S9 | `*SET:LED 00` | `OK LED AUTO` | 退出 LED 接管，恢复自动 LED 状态 |
| S10 | `*SET:MODE NIGHT` | `OK MODE`，可伴随 `*EVT:MODE NIGHT` | 仅显示时分，LED 仅保留心跳 |
| S11 | `*SET:MODE DAY` | `OK MODE`，可伴随 `*EVT:MODE DAY` | 恢复完整显示 |
| S12 | `*SET:WEA 31 SUN` | `OK WEA` | 天气数据保存，相关 LED 更新 |
| S13 | `*SET:MSG HELLO S800 CLOCK` | `OK MSG` | 消息滚动一整圈后自动回时间 |
| S14 | `HELLO S800 CLOCK` | `OK MSG` | 裸文本按消息处理 |
| S15 | `*NTP SYNC` | `OK NTP` | NTP 状态 LED 点亮 |

## 3. LED 含义

| LED 位 | 含义 |
|---|---|
| LED0 | 系统心跳 |
| LED1 | 闹钟使能或响铃状态 |
| LED2 | 编辑模式 |
| LED3 | UART 收发活动 |
| LED4 | 天气晴 |
| LED5 | 雨雪天气 |
| LED6 | 高温提示 |
| LED7 | NTP 已同步 |

说明：执行 `*SET:LED <hex2>` 后会进入 LED 接管模式；发送 `*SET:LED 00` 或 `*RST` 后恢复自动 LED 语义。

## 4. 按键功能速查

| 按键 | 功能 |
|---|---|
| `FUNC` | 进入/切换编辑模式；闹钟响铃时停止响铃 |
| `SHIFT` | 编辑状态下切换字段 |
| `ADD` | 编辑状态下当前字段加 1 |
| `SAVE` | 保存并退出编辑 |
| `DISP` | 时间、短日期、长日期循环显示 |
| `SPEED` | 滚动速度切换 |
| `FORMAT` | 显示方向 LEFT/RIGHT 切换 |
| `EXT` | 预留扩展键，上报按键事件 |
| `USER1` | 请求 PC 执行 NTP 对时 |
| `USER2` | 短显天气信息 |

## 5. 5 分钟演示脚本

### 0:00 - 0:30 项目介绍

讲解词：

> 本项目实现了一个基于 S800 板和 PC 上位机的智能联网时钟。板端可以独立完成时间、日期、闹钟、按键编辑和 LED 状态显示；PC 端通过串口实现远程控制、状态监视、数字孪生镜像，以及 NTP 对时、天气下发、自动昼夜模式和自动化验收。

画面：

- 展示 S800 板。
- 展示 PC 上位机主界面。

### 0:30 - 1:20 板端基础功能

操作：

1. 观察默认时间显示。
2. 按 `DISP` 三次。
3. 按 `FORMAT` 切换显示方向。
4. 简单演示 `FUNC`、`SHIFT`、`ADD`、`SAVE` 编辑流程。

讲解重点：

- 1 ms 系统节拍驱动时间递增。
- 日期和时间独立维护。
- DISP 已限制为时间、短日期、长日期循环。
- RIGHT 模式小数点位置正确。

### 1:20 - 2:10 PC 数字孪生同步

操作：

1. PC 选择 COM 口并连接。
2. 展示日志中的 `*EVT:DISP` 和 `*EVT:LED`。
3. 对比板端和 PC 数码管、小数点、LED。
4. 点击 PC 虚拟 `DISP` 或 `FORMAT`。

讲解重点：

- PC 面板是 1:1 数字孪生。
- 板端每秒主动上报显示和 LED 状态。
- PC 虚拟按键通过 `*SET:KEY <NAME>` 等效控制板端。

### 2:10 - 3:10 PC 控制与协议

操作：

1. 点击设置时间或日期。
2. 发送 `*SET:BEEP 500`。
3. 发送 `*SET:LED 3F`，再发送 `*SET:LED 00`。
4. 输入 `HELLO S800 CLOCK` 或 `*SET:MSG HELLO S800 CLOCK`。

讲解重点：

- 串口协议统一使用 ASCII 行命令。
- 支持参数化命令、错误处理和裸文本消息。
- 消息滚动一圈后自动回到时间显示。

### 3:10 - 4:10 扩展功能

操作：

1. 点击 `NTP Sync`。
2. 展示 `OK DATE`、`OK TIME`、`OK NTP`。
3. 点击 `Fetch Weather` 或发送天气。
4. 按 `USER2` 展示天气短显。
5. 点击 `Auto Day/Night`。

讲解重点：

- NTP 对时由 PC 获取时间并下发给板端。
- USER1 可以从板端反向触发 PC 对时。
- 天气通过 PC 获取或手动下发，板端用数码管和 LED 展示。
- 自动昼夜模式根据上海日出日落计算。

### 4:10 - 4:50 自动化验收

操作：

1. 点击 `Run Smoke Test`。
2. 等待结果显示 `Passed 13/13`。
3. 展示最后一项 `BEEP RANGE ERROR` 返回 `ERROR RANGE`。

讲解重点：

- Smoke Test 自动覆盖 PING、SET/GET TIME、格式、显示开关、LED、蜂鸣、虚拟按键和错误处理。
- `*SET:BEEP 9999` 是预期错误用例，返回 `ERROR RANGE` 代表错误处理正确。

### 4:50 - 5:00 总结

讲解词：

> 本系统完成了板端独立时钟、双向串口协议、PC 数字孪生、远程控制、NTP、天气、自动昼夜模式和自动化测试。最终联调结果显示 Run Smoke Test 通过 13/13，说明主流程和协议异常处理均正常。

## 6. 录屏注意事项

- 录屏前先关闭 SSCOM，避免 COM 口被占用。
- 录屏时窗口布局建议：左侧拍摄板子，右侧显示 PC 上位机。
- 演示 `Run Smoke Test` 前先确认板子处于 DAY 模式，LED 不是手动接管状态，必要时发送 `*RST`。
- 如果 `Fetch Weather` 受网络影响失败，可以说明支持手动天气下发，并用 `*SET:WEA 31 SUN` 演示。
- 保留 `Passed 13/13` 的截图或录屏片段作为最终验收证据。
